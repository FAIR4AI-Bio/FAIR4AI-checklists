Description

The Cooperative-Breeding Database (Co-BreeD) is an updateable database that curates population-level estimates of biological parameters relevant to cooperative breeding research of birds and (human and non-human) mammals. Please refer to Ben Mocha

et al.

(2025) for a comprehensive overview of the database.

The Co-BreeD folder contains 4 files:

(a) Co_BreeD_V1__read_me.R :

This R script

includes instructions about the 5 dataframes included in the Co_BreeD_V1.RData and can be used to view the database.

(b)

Co_BreeD_V1.RData :

This RData file includes the Co-BreeD database and accompanying dataframes.

(c) Co_BreeD_V1__quality_check.R :

An r script to check for inconsistencies in each column of the database.

(d) Co_BreeD_V1__data_submission_template

: A data submission form for data contributors. Data contributors (i.e., data on any type of parental care in any wild population of any individually marked bird or mammal species) are acknowledged by an offer to join as co-authors of the next Co-BreeD manuscript (contact Yitzchak Ben Mocha for more details:

yitzchakbm@gmail.com

).

Ben Mocha

et al.

(2025) An integrative, peer-reviewed and open-source Cooperative-Breeding Database (Co-BreeD).

Journal of Animal Ecology
