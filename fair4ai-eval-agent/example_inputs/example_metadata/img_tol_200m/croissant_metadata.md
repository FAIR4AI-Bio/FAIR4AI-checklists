**Description highlights:** The dataset contains around 233 million images spanning 933,798 taxa, described as "the largest and most diverse public ML-ready dataset for computer vision models in biology at release." It draws from four biodiversity providers: GBIF, EOL, BIOSCAN-5M, and FathomNet.

**Format:** Parquet files (Croissant 1.1 conformant), sourced from a Hugging Face git repository.

**Key fields in the record set** include: split, uuid, source_url, taxonomic ranks (kingdom, phylum, class, order, family, genus, species), scientific_name, common name, data_source, publisher, basis_of_record, img_type, source_id, and various file path fields.

**Keywords include:** image-classification, zero-shot-classification, biology, taxonomy, multimodal, clip, and more.
