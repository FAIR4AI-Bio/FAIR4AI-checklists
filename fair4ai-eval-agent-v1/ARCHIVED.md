# Archived: FAIR4AI Evaluation Agent v1

This folder contains the v1 Python-script-based FAIR4AI evaluation agent (`fair4ai_agent.py`). It supports OpenAI, Azure OpenAI, and Anthropic as LLM providers and uses a 135-question Google Forms-derived checklist.

For the current agent (Claude Code slash command / GitHub Copilot / ChatGPT, platform-agnostic), see [`fair4ai-eval-agent/`](../fair4ai-eval-agent/).
